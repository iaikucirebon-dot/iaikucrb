## INSTITUT AGAMA ISLAM KANZUL ULUM CIREBON (IAIKU CIREBON)

**Institut Agama Islam Kanzul Ulum Cirebon (IAIKU Cirebon)**

Website: **iaikucrb.ac.id**

### 1. KONSEP DESAIN

Buat website dengan gaya:

* Modern
* Profesional
* Elegan
* Islami
* Akademik
* Bersih dan terpercaya
* Responsive untuk desktop, tablet, dan mobile
* Menggunakan desain modern seperti website perguruan tinggi ternama
* Memiliki nuansa **Islamic Modern University**
* Tidak terlalu banyak ornamen Islami agar tetap terlihat modern
* Gunakan whitespace yang cukup
* Gunakan animasi ringan dan smooth
* Gunakan efek hover pada tombol, kartu program studi, fasilitas, dan berita
* Gunakan typography yang modern dan mudah dibaca

### 2. IDENTITAS UTAMA

Nama:
**Institut Agama Islam Kanzul Ulum Cirebon**

### 3. WARNA WEBSITE
